
## Getting Started

### Backend
bash
cd restaurant-pos-backend
npm install
npm start

### Frontend
bash
cd restaurant-pos-frontend
npm install
npm start

Create a `.env` file in the backend folder with your own MongoDB URI, JWT secret, and other credentials — never commit real API keys or secrets.
